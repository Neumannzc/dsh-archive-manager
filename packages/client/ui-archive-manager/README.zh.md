# @deepseek-ai/dsh-client-ui-archive-manager

[English](README.md) | 中文

归档管理插件：一个设置页（`settings.section`，id 为 `archives`，排在 agent 预设页之后），列出已归档的会话并支持取消归档。

归档是一种显示集操作：宿主把会话 id 移入注册表全局归档集，会话便从所有分组表面消失——工作区分组、未分组桶、内容搜索与单列表——而会话日志与其工作区记账槽位保持不变，因此取消归档会恢复到原来的位置。本节展示该隐藏集合：归档会话按工作区分组显示，与未归档的浏览器树完全一致（工作区注册表顺序、组内记账顺序、以及工作区之外归档会话的尾部未分组桶），每一行都带有一个取消归档操作。行在单向回显时从本节消失，侧边栏又从同一个归档集快照中将其重新拾取——本地回显与远端标签页的帧通过同一个 `host/archived-sessions-changed` 源收敛。

每个分组都可以像侧边栏一样折叠：组头行（箭头、工作区标题、会话计数）切换其行的显示，行只在展开时渲染，分组默认折叠。展开状态存于注册时声明的视图 store，并持久化到 localStorage（`dsh.archiveManager.expanded.v1`），因此设置页重挂载与刷新后状态不变；全部会话都被取消归档的分组会清除其记录，之后重新归档时从折叠开始。

本节只读取框架的全局数据源（`useSessions` 与 `useWorkspaces`，即侧边栏派生所用的同一快照）与 workspaces 服务的 `unarchiveSession` RPC；唯一自有的 store 就是上述视图状态，不拥有任何宿主状态。空白占位会话与子代理子会话的排除规则与浏览器树一致，因此归档视图与未归档视图完全镜像。

## Model Experience

无；本节只是现有宿主 RPC 之上的浏览器界面，不触及任何模型请求。

#### KV Cache effect

无；本包既不组装也不发送任何 provider 请求。

## Known Limitations and Deferred Work

- **本节不提供重新归档操作** —— 恢复操作发生在工作区浏览器的行菜单（归档会话）中，与归档时的操作一致；本节刻意只提供别处无法到达的方向。
- **未分组桶不携带工作区上下文** —— 工作区之外的归档会话（例如工作区注册删除之后）只显示标题，与浏览器自身的未分组行一致。
